# NPC group opportunity (static POPCYCLE audit)

Derived from [population-catalog.json](population-catalog.json), which records `20` type blocks and `480` weekday/weekend time rows. The header is `data/popcycle.dat:20`. This is configured group opportunity conditional on type/schedule selection; it is not an observed frequency, probability, spawn density, or proof that Eagle selects a particular zone/type/pedgrp file at runtime.

The audit covers the 18 composition fields after `other_pct`. `dealers_pct`, `gang_pct`, and `cops_pct` are separate POPCYCLE fields and are excluded. The spelling `Crimimals` is preserved for the source header/field key (`crimimals_pct`); the configured ped group uses `POPCYCLE_GROUP_CRIMINALS`.

## Shortlist guidance for favorite replacements

For a first broad ambient shortlist, start with **Casual Average (12 blocks, 220 positive rows)**, then consider **Business (11 blocks, 115 rows)** and **Casual Poor (11, 136 rows)**, followed by **Casual Rich (9 blocks, 173 rows)**. These labels cover everyday street/social roles across many configured type blocks. This is a configuration-breadth rationale, not a score and not a claim that their models are more likely to spawn.

Keep **Clubbers** as a scene-specific option: positive rows are mostly 8pm–4am, with a 6am entry in `SHOPPING_POSH`; there are no weekday 8am–6pm positives. Workers, Farmers, BeachFolk, Parkfolk, Golfers, Servants, Aircrew, Entertainers, Out-of-Town Factory Workers, Desertfolk, and Aircrew_runway are narrower occupation/place/theme choices. Prozzies and Crimimals map to configured Prostitutes and Criminals groups; treat them as deliberate specialist choices even though their POPCYCLE fields are positive in many type blocks. Verify intended character suitability before allocating favorites to these groups.

Use `npc-group-opportunity.json` for every positive row condition (type, weekday/weekend, exact slot label, numeric field value, and source line), plus each category's all-zero type-block list and cross-file pedgrp-label presence. Do not convert the numeric field values into spawn percentages.

## Scope limits

- The category values describe configured composition fields inside `Other`; they are not direct per-model chances.
- The source inventory says `data/pedgrp*.dat` files are not explicitly mounted by selected `data/gta.dat`; which file is used at runtime remains unverified.
- There is no verified `zone -> POPCYCLE type -> pedgrp file/group row` mapping here. Do not assign these opportunities to Los Santos, Vice City, or Carcer from this audit.
- A model appearing in a pedgrp row does not establish that it is selected or visible in a live game. This audit did not launch the game.
- Later favorite allocation should combine the user's selected characters and thematic fit with their model weight/texture cost and the relevant group memberships, then be reviewed before implementation.
