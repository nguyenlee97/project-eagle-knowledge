The 434 nonmatching pairs are not evidence that the assets are unused; ID 0's `null` placeholder and special IDs 290–299 require alias/script/trainer resolution before drawing conclusions about where they load from.

There is a source-resolution caveat: `modloader.ini` selects the Default profile, with `IgnoreAllMods=false` and `ExcludeAllMods=false`, while `.data/plugins/plugins.ini` sets `gta3.std.stream=0`. The Mod Loader's bundled `std.stream` documentation says that plugin handles loose DFF/TXD streaming and IMG overrides. Thus the loose copies' presence and inclusion under the profile do not by themselves establish that those loose files are the source used at activation. The archive is independently declared in `default.dat`; the available evidence does not identify which route F2 uses.
