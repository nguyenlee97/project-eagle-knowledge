# Revision: flat 2D anime / black-and-white branding

User direction, 14/10/2026: the first gold/black logos and glossy 2.5D pilot were rejected. Both logos now use white/black, and the artwork must use flat anime 2D rendering.

- White lettering with black outline; grayscale antialiasing only. No gold logo, metallic highlight, bevel or 3D treatment.
- Project Wibu uses a flat Hu Tao silhouette with a white perimeter keyline and recognizable hat/flower/hair outline.
- Artwork retains color, but uses clean lineart, flat fills and one hard-edged shadow tone per material. The car, background and character rendering follow the same 2D language.
- No glossy skin/cars, airbrushed volume, bloom, bokeh, photorealistic lighting or depth blur.
- Keep the approved 23 female characters, urban outfits, GTA composition, wordmark spelling, target texture dimensions and separate dynamic loading UI.
